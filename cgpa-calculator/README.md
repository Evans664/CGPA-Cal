# CGPA Calculator

A simple, fast and mobile-friendly CGPA calculator built by the Evans Builds team.

## Description

This is a client-side MVP for entering courses and calculating GPA from an approved grading configuration. The grading system is intentionally unresolved and is not included yet.

## Features

- Welcome screen
- Course entry with course code, credit units, and grade
- Add and remove courses
- Input validation
- GPA result display
- Reset flow
- Responsive design

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

No frameworks, packages, backend, server, API, database, or authentication are used.

## How to Run

Open `index.html` in a modern web browser. No installation, build step, package manager, or server is required for the starter project.
